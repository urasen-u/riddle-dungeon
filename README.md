プロジェクト名　激突！クイズアドベンチャー

【概要】
企画・UI設計・プログラム実装・リリースまでを一人で完遂したUnityゲームです。(一番下にunityroomのリンクあります)

【使用技術・環境】

・Engine: Unity 6000.4.2f1

・Language: C#

・Version Control: Git / GitHub

[ゲーム概要]
ダンジョンを進み、クイズで戦うRPGゲームです。
ダンジョン内で手に入れたアイテムやレリックを駆使して最深部で待ち構えるボスの撃破を目指しましょう！

[技術的背景]
・クイズデータのScriptableObject化
ScriptableObjectを用いてクイズを管理することで後からクイズの追加をしやすくなるように工夫をしました。

・アイテム及びレリックのScriptableObject化
アイテムやレリックもScriptableObjectを用いて後からの追加が簡単になるように工夫しました。

・クイズのシャッフルと重複防止
クイズは1度出題されたものは、同じ難易度のクイズが全て出るまで出題されないようにしました。
また、同じクイズでも、選択肢の順番は毎回変わるので、番号で覚えるといったことを対策しています。

・バトルの演出
攻撃時には敵の点滅とランダムなエフェクトが発生し、敵の撃破時には撃破時用の演出が発生し、戦闘の見栄えを豪華にすることに
成功しました。また、被弾時と攻撃時にはダメージ量に応じたボイスも再生され、戦闘の迫力を向上させています。
